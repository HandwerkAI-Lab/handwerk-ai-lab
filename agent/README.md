# Agent (HERMES)

Local business agent on the Mac Studio, using the Sparks as OpenAI-compatible inference backends.

Only **templates** live here. Real configs, API keys, hostnames and all customer data stay local.

- `config.example.yaml` – provider template (copy to `~/.hermes/config.yaml`)

Use cases: customer inquiry drafts, shop copy, quote drafts. Rule: the agent drafts, a human sends.
